# Plano de Acesso e Edição - Reposicione-se

## Status do repositório

Repositório: `Sollimastudio/ecossistema-editorial-inteligente`

Status inicial encontrado: repositório privado e vazio.

Base editorial criada para começar a edição do livro com organização, versionamento e skills editoriais.

## Como a IA deve acessar este projeto

1. Ler o `README.md`.
2. Ler as skills em `.claude/skills/`.
3. Localizar a versão mais atual em `manuscrito/`.
4. Auditar estrutura, sumário, títulos, páginas de abertura, excesso e lacunas.
5. Criar relatório em `relatorios/` antes de mexer pesado no texto.
6. Editar sempre em nova versão, nunca sobrescrever.

## Arquivo necessário para iniciar a edição real

Para editar de verdade, o livro precisa estar em formato editável:

- Markdown `.md`, preferencial;
- DOCX `.docx`, aceitável;
- PDF apenas para conferência visual, não como base principal de edição.

## Fluxo recomendado

### Rodada 1 - Diagnóstico

- Conferir sumário.
- Identificar páginas quebradas.
- Separar pré-livro, partes, capítulos e apêndices.
- Listar problemas estruturais.

### Rodada 2 - Limpeza

- Corrigir títulos grudados.
- Remover textos de bastidor do corpo do livro.
- Separar testes longos para caderno próprio.
- Reduzir repetição sem perder assinatura do método.

### Rodada 3 - Edição Sol

- Reforçar voz autoral.
- Trocar tom de IA palestrante por linguagem viva.
- Criar respiros, comandos, checkpoints e frases de impacto.

### Rodada 4 - Pré-diagramação

- Marcar boxes.
- Marcar infográficos.
- Marcar páginas de abertura.
- Criar mapa visual final.

### Rodada 5 - Produção

- Gerar DOCX revisado.
- Gerar PDF boneco.
- Revisar no celular.
- Revisar impresso.
- Só então fechar versão final.

## Regra central

Reposicione-se não será tratado como arquivo solto.
Será tratado como obra, método e produto editorial premium.

Sem gambiarra com glitter.
