# Ecossistema Editorial Inteligente

Repositório de trabalho para a edição, revisão, organização e produção editorial do livro **Reposicione-se™**, de **Sol Lima**.

Este repositório não é apenas um depósito de arquivos. Ele é a base operacional do processo editorial: manuscrito, versões, relatórios, prompts, skills editoriais, mapas visuais, caderno de testes e preparação para PDF/DOCX premium.

## Obra principal

**Reposicione-se™**  
Frase-mestra: **O mundo ensinou você a reagir. Ninguém te ensinou a existir.**

## Objetivo

Transformar o material atual em uma versão editorialmente limpa, respirável, premium e publicável, preservando:

- voz autoral de Sol Lima;
- Método Posicione-se™;
- Árvore do Discernimento;
- Comandos da Árvore;
- Comandos do Pensamento;
- Filtro da Sensatez™;
- Pragas da Árvore;
- ponte com Morte em Vida;
- estética Dark Luxury Editorial Simbólico.

## Estrutura inicial

- `.claude/skills/` — skills editoriais para agentes de IA.
- `manuscrito/` — versões do texto do livro.
- `relatorios/` — auditorias, pareceres e diagnósticos editoriais.
- `prompts/` — prompts-mestres de edição e revisão.
- `mapa-visual/` — plano de imagens, infográficos e páginas especiais.
- `scripts/` — ferramentas automáticas de marcação, auditoria e conversão.

## Regra de ouro

Nenhum script substitui revisão humana.  
O script marca.  
A editora decide.  
A autora dá alma.  

Porque livro premium não nasce apertando botão. Isso aí é impressora, não literatura.
