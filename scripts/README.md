# Scripts Editoriais

Esta pasta receberá ferramentas automáticas para ajudar no processo editorial.

## Scripts previstos

1. Marcador editorial de Markdown.
2. Auditor de títulos e sumário.
3. Detector de capítulos longos.
4. Detector de repetição forte.
5. Gerador de mapa visual.
6. Conversor DOCX/PDF quando aplicável.

## Regra de uso

Script não decide versão final.

Script marca.
Editor revisa.
Autora aprova.
Designer diagrama.

Se o script tentar virar escritor, mande ele subir na árvore e pensar no que está fazendo.
