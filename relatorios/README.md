# Relatórios Editoriais

Use esta pasta para guardar auditorias e pareceres sobre o livro **Reposicione-se**.

## Tipos de relatório

- auditoria estrutural;
- revisão de sumário;
- mapa de excesso e repetição;
- checklist de diagramação;
- parecer de prontidão para publicação;
- relatório de imagens e infográficos;
- revisão de riscos técnicos, jurídicos e espirituais.

## Regra editorial

Relatório bom não é o que fala bonito.
Relatório bom é o que aponta o problema e diz o próximo passo.

Sem fumaça. Sem bajulação. Sem drama teatral. Livro já dá trabalho suficiente.
