# Plano Operacional — V03 Edição por Partes

Projeto: **Reposicione-se™**  
Autora: **Sol Lima**

## Veredito

A edição do livro será feita por partes, em rodadas curtas e controladas.

Não vamos gerar o livro inteiro de uma vez agora.

Antes, vamos construir uma versão editável, visualmente planejada e aprovada por blocos. O erro anterior foi tentar transformar tudo em PDF completo antes de fechar texto, visual, template e QA. Agora o processo será editorial, não gambiarra com perfume de Canva.

## Camadas oficiais do projeto

### 1. Texto limpo

Base: `manuscrito/reposicionese_v02_limpeza_estrutura.md`

Função:

- estrutura textual;
- partes;
- capítulos;
- sumário limpo;
- blocos realocados;
- base para edição fina.

### 2. Imagens didáticas

Base: imagens geradas e tabela visual.

Função:

- ancorar conceitos;
- abrir partes;
- aliviar densidade;
- guiar a leitura;
- transformar método em memória visual.

### 3. Template editorial

A criar e testar.

Função:

- formato 6x9;
- margens;
- corpo de texto;
- títulos;
- subtítulos;
- boxes;
- checkpoints;
- páginas inteiras de imagem;
- páginas de abertura.

### 4. QA visual

A cada entrega curta.

Função:

- impedir páginas brancas sem função;
- impedir fonte pequena;
- impedir gráfico sumido;
- impedir título grudado;
- impedir PDF grande demais sem motivo.

## Como cada rodada será entregue

Cada rodada terá:

1. texto editado em Markdown;
2. mapa visual do trecho;
3. lista de cortes ou realocações;
4. imagens associadas;
5. preview curto em DOCX/PDF quando necessário;
6. QA visual antes de aprovar.

## Critério de aprovação por rodada

A rodada só passa se:

- o texto estiver mais claro;
- a voz estiver mais Sol;
- os conceitos estiverem preservados;
- a leitura respirar;
- as imagens tiverem função;
- não houver página vazia sem intenção;
- não houver fonte pequena;
- o bloco puder entrar no livro final.
